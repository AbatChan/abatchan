What the guide does, and does not do.
It knows the visitor’s current page, the visible text on that page, published work, pricing, process and how to contact Abat. Page text is treated as untrusted context, never as instructions. It cannot access accounts, take payments, send messages, reveal private settings, provide code or hacking help, or make binding promises. Those boundaries are fixed in the server and cannot be weakened by this prompt. Rate limits and model failures automatically show visitors a retry action and a contact-support button.
The API key is not set here, on purpose.
Public settings are readable with the publishable key, while the system prompt stays behind row-level security. The DeepSeek key lives as DEEPSEEK_API_KEY in Vercel → Settings → Environment Variables, where only /api/chat can read it. Never paste a secret into this dashboard.

Announcements

Visitors see the first announcement they have not dismissed. Closing it or following its button hides that ID permanently on that device.

Dismissal is stored against the ID. A new ID is intentionally treated as a new announcement.
